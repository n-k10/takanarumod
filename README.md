# takanarumod

Minecraft Forge 1.20.1 のModding入門リポジトリです。

## Step 25: 進捗（実績）を追加しよう

このステップでは、銀に関する進捗（実績）ツリーを追加します。
これまで作ってきた全てのコンテンツを進捗で結びつける、カリキュラムの最終ステップです！

### 進捗ツリー
```
銀の時代（銀を手に入れた）
├── 銀の武装（剣とツルハシを作った）
├── 銀の騎士（防具をすべて揃えた）
│   └── 銀のマスター（全ツール・防具・探知機を収集）★チャレンジ
└── 銀の祝福（銀のリンゴを食べた）
```

### やること
- 進捗JSONファイルを5つ作成する
- 翻訳ファイルに進捗のタイトルと説明を追加する
