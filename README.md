# takanarumod

Minecraft Forge 1.20.1 のModding入門リポジトリです。

## Step 06: 日本語対応しよう

このステップでは、Modの表示名を日本語に翻訳します。
Minecraftの言語設定を「日本語」にすると、日本語名で表示されるようになります。

### やること
- 日本語翻訳ファイル [`ja_jp.json`](src/main/resources/assets/takanarumod/lang/ja_jp.json) を作成する
- これまでに追加したアイテム・ブロック・タブの日本語名を設定する

### 追加するファイル
| ファイル | 種類 |
|---------|------|
| [`src/main/resources/assets/takanarumod/lang/ja_jp.json`](src/main/resources/assets/takanarumod/lang/ja_jp.json) | 新規 |

### テクスチャ
このステップでは新しいテクスチャは不要です。
